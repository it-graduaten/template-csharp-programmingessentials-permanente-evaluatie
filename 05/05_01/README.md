# 05_01

Maak een programma dat de gebruiker vraagt hoeveel lijnen hij of zij wil tonen. Het programma toont vervolgens die hoeveelheid lijnen, waarbij elke lijn een willekeurige tekst bevat. Gebruik een for-lus om de lijnen te tonen.

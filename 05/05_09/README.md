# 05_09

Maak een programma dat de gebruiker vraagt naar een geheel getal. Het programma toont vervolgens de vermenigvuldigingstabel van dat getal van 1 tot en met 10, elk op een eigen regel in de vorm "getal × teller = resultaat".

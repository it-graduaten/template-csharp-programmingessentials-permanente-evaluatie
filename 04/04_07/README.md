# 04_07

Een gebruiker wil een lijst van zijn favoriete kleuren bijhouden. Gebruik een List<string> om dit te doen.

Vraag de gebruiker om vier kleuren in te voeren. Voeg elke kleur toe aan de lijst.

Vraag daarna of de gebruiker een vijfde kleur wil toevoegen. Als ja, vraag dan welke kleur en voeg deze toe.

Tonen: het totaal aantal kleuren in de lijst en alle kleuren op een nieuwe regel.

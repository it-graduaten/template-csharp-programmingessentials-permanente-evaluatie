# 04_00

Een school wil de dagelijkse afwezigheid bijhouden. Er zijn precies drie lessen op deze dag. Gebruik een array om het aantal afwezigen per les bij te houden.

Vraag de gebruiker om het aantal afwezigen voor elke les. Sla de resultaten op in een int-array van grootte 3.

Tonen: het totaal aantal afwezigen over alle lessen en hoeveel lessen geen enkel afwezige hadden.

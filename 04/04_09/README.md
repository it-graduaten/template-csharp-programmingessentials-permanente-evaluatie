# 04_09

Een school wil de gemiddelde score berekenen voor een toets met precies vijf studenten. Gebruik een array om de scores op te slaan.

Vraag de gebruiker om de score van elke student in te voeren. Sla de scores op in een int-array.

Bereken het gemiddelde van alle scores en toon het resultaat.

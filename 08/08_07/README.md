# 08_07

Maak een programma dat de gebruiker om een getal vraagt en bepaalt of het getal een priemgetal is. Een priemgetal is een getel groter dan 1 dat alleen deelbaar is door 1 en zichzelf.

Het programma moet een methode bevatten die een int als parameter ontvangt en een bool teruggeeft: true als het getal een priemgetal is, false anders.

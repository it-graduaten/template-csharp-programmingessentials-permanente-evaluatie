# 07_00

Maak een programma dat de gebruiker om zijn naam vraagt en deze weergeeft met een welkomstboodschap. Het programma moet een void methode hebben die de boodschap afdrukt.

De methode ontvangt de naam als parameter en geeft het volgende formaat weer: "Welkom, [naam]!"

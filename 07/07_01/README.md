# 07_01

Maak een programma dat een void methode aanroept om een menu op het scherm te tonen. Het menu toont de volgende opties:
1. Optellen
2. Aftrekken
3. Vermenigvuldigen

De gebruiker kiest een optie en het programma vraagt vervolgens om twee getallen in te voeren. Het programma voert de gekozen bewerking uit op de twee getallen en toont het resultaat.
